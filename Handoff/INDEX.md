# HandOff 색인

## 목적

이 폴더는 개인 작업의 완료 내용, 현재 상태, 다음 작업, 검증 근거를 짧게 이어가기 위한 durable 기록이다. 기능 명세, QA 이슈, 릴리스 이력, 리팩터링 backlog의 원본은 기존 `Docs/` 문서를 유지한다.

## 현재 작업자

| 작업자 | HandOff | 현재 상태 |
| --- | --- | --- |
| 윤달 | [윤달 HandOff](윤달_HandOff.md) | Presentation 리팩터링 진행 중 |

## 운영 규칙

- 작업자는 자신의 HandOff만 수정한다.
- 다른 작업자의 HandOff는 읽을 수 있지만 수정하지 않는다.
- 코드, 문서, 리팩터링, 검증 작업을 완료한 뒤 Current, Recent Work, Next, Validation을 간결하게 갱신한다.
- 상세 기록이 최신 상태 파악을 방해하면 `archive/`로 이동한다.
- archive는 과거 근거이며, 현재 작업은 개인 HandOff와 `INDEX.md`를 우선 확인한다.
