# RODI 2차 업데이트

이 문서는 2차 업데이트 범위의 연습 측정, 외부 길안내 복귀, 방문 인증, 후기 팝업을 다룬다.
동작의 최종 원본은 `Rodi/App/RootReducer.swift`, `Rodi/Presentation/PracticeTracking`,
`Rodi/Core/Service/PracticeMeasurementStore.swift`다. API 계약은 `Docs/API_SWAGGER.md`를 확인한다.

## 연습 코스 팝업 환경 차이

팝업의 문구·버튼·우선순위는 Dev와 Prod에서 같다. 차이는 테스트를 위한 조건뿐이다.

| 항목 | Dev (`Rodi Dev` Debug) | Prod (`Rodi` Release) |
| --- | --- | --- |
| 외부 길안내 체류 후 후기 팝업 조건 | 10초 이상 | 10분 이상 |
| 활성 GPS 측정 중 Rodi 재진입 | `아직 코스를 연습 중이신가요?` 지속 확인 팝업 | 동일 |
| GPS 인증 완료 뒤 Rodi 재진입 | 체류 시간 충족 시 `연습은 잘 다녀오셨나요?` | 체류 시간 충족 시 동일 |
| 경로만 보기 뒤 Rodi 재진입 | 10초 이상일 때 후기 팝업 | 10분 이상일 때 동일 |
| 빈 추천 목록의 테스트 페이지 | Live Activity 및 후기 팝업 테스트 진입 가능 | 노출하지 않음 |
| 주차장 `다녀왔어요`의 GPS 미인증 등록 | 연습기록 등록·방문 POST를 허용 | 동일 |
| 코스 `다녀왔어요`의 GPS 미인증 등록 | 연습기록 등록·방문 POST 후 후기 작성으로 이동 | GPS 방문 인증 완료 기록만 유지하고 후기 작성으로 이동 |

## 팝업 우선순위와 종료

1. 활성 GPS 측정이 남아 있으면 재진입 시 지속 확인 팝업을 먼저 노출한다.
2. `측정 종료`를 선택한 뒤에도 외부 체류 시간이 충족된 경우에만 후기 팝업 후보가 된다.
3. 인증 완료 또는 경로만 보기 후보의 외부 체류 시간이 충족되면 후기 팝업을 표시한다.
4. 후기 팝업의 `안 했어요`, `다녀왔어요`는 해당 측정 후보를 제거한다. X는 후기 작성을
   나중으로 미루는 동작으로 처리한다. GPS 인증 완료 기록은 유지하며, Dev의 GPS 미인증 코스는
   연습기록·방문 POST를 먼저 완료한 뒤 팝업만 닫는다.

외부 앱을 열기 직전에 측정 후보와 시각을 저장한다. 외부 앱 전환으로 앱이 suspend되더라도
체류 시간이 복귀 시각으로 초기화되지 않도록 하기 위함이다. 외부 앱 열기에 실패하면 후보를 제거한다.

## 방문 인증과 연습기록

- GPS 측정은 코스 경로 150m 이내 이동만 인정하며, 인증 필요 거리는
  `min(코스 전체 거리 × 0.4, 5km)`다.
- 인증 완료 시 `POST /api/v1/places/{placeId}/practices` 후
  `POST /api/v1/practices/{practiceId}/visits`를 호출한다.
- 주차장은 GPS 측정으로 장소 범위에 진입하면 인증을 완료하며, 후기 작성은 지원하지 않는다.
- 주차장 후기 팝업의 `다녀왔어요`는 GPS 인증 여부와 관계없이 연습기록·방문 POST를 호출한다.
  이미 GPS 인증으로 기록이 생성된 경우에는 중복 호출하지 않고 스낵바만 표시한다.
- Debug에서 GPS 인증 전에 종료한 코스도 후기 팝업의 `다녀왔어요`를 누르면 연습기록·방문 POST를
  먼저 호출한 뒤 후기 작성으로 이동한다. Prod에는 이 우회를 적용하지 않는다.
- Debug에서 GPS 인증 전에 종료한 코스의 후기 팝업 X도 연습기록·방문 POST를 먼저 호출하고,
  후기 작성 화면으로 이동하지 않는다. 이후 연습기록의 `후기 작성`으로 다시 작성할 수 있다.
- 코스·주차장 모두 후기 팝업의 `안 했어요`는 미방문 사유 작성으로 이동한다.

## GPS 측정·배터리·완료 정책

### 위치 수집과 개인정보

- Live Activity가 허용되고, 위치 서비스·정밀 위치 권한이 모두 허용된 `GPS 측정`에서만 외부 길안내와 함께
  백그라운드 위치 수집을 시작한다. 외부 앱 열기에 실패하면 측정을 취소한다.
- 활성 측정 중에는 차량 주행(`automotiveNavigation`) 용도로 수집하며, iOS 17 이상에서는
  `CLBackgroundActivitySession`도 함께 유지한다. 완료·취소·프로세스 재시작으로 인한 중단 시에는 위치 수집과
  백그라운드 위치 업데이트를 즉시 종료한다.
- UserDefaults에는 장소 ID·이름·측정 상태·시각·인증 거리만 저장한다. 사용자의 원본 GPS 좌표나 이동 궤적은 저장하지 않는다.

### 배터리 절감형 위치 정책

| 측정 단계 | 목표 위치 정확도 | 최소 이동 간격 | 목적 |
| --- | --- | --- | --- |
| 코스 진입 전 | 약 100m | 100m | 코스 범위 진입만 확인해 배터리 사용을 낮춘다. |
| 코스 주행 중 | 약 10m | 20m | 인정 주행거리와 연습 진행률을 계산한다. |
| 주차장 이동·도착 확인 | 약 100m | 100m | 주차장 범위 진입만 확인한다. |

- 목표 정확도와 이동 간격은 Core Location에 전달하는 요청값이므로, 실제 위치 콜백 간격·배터리 사용량은 기기,
  GPS·네트워크 상태, iOS의 전력 관리 정책에 따라 달라질 수 있다.
- Live Activity는 위치가 들어올 때마다 갱신하지 않는다. 단계 변경, 15초 경과, 또는 진행률 3% 이상 변화 시에만 갱신한다.

### 코스 인증과 Live Activity 완료

- 위치 정확도 60m 이하의 최신 위치가 코스 polyline에서 150m 이내일 때만 정상 코스 주행으로 본다.
  범위를 벗어나면 직전 위치를 끊어, 범위 밖 이동거리가 재진입 뒤에 누적되지 않게 한다.
- 인정 구간 안의 연속 GPS 이동거리를 누적한다. 반복·왕복 주행과 코스 중간 진입도 인정하며,
  비정상 점프는 최대 45m/s와 80m 여유 기준으로 제외한다.
- 완료에 필요한 거리는 `min(코스 전체 거리 × 0.4, 5km)`다. 누적 인정거리 ÷ 필요 거리로 연습 진행률을 계산하고
  최대 100%로 제한한다. 임계값 도달 시 측정을 종료하고 방문 인증 요청을 시작하며, Live Activity를 완료 상태로
  갱신한 뒤 최대 30분 동안 표시한다.

### 주차장 인증과 Live Activity 완료

- 주차장은 장소 좌표 주변의 150m 범위에 들어오면 즉시 완료한다. 주행거리·연습 진행률은 계산하지 않으므로
  Live Activity에 출발·도착 진행바를 표시하지 않는다.
- 범위 진입 시 위치 수집을 종료하고, 코스와 같은 완료 Live Activity 상태로 전환한다. 방문 인증 요청에는 거리값을 보내지 않는다.

## 화면·선택지별 처리표

### 활성 측정 지속 확인 팝업

코스·주차장 및 Dev·Prod에 공통으로 적용한다.

| 선택 | 결과 |
| --- | --- |
| `계속 측정` | 팝업만 닫고 기존 GPS 측정과 Live Activity를 유지한다. |
| X | `계속 측정`과 동일하다. 실수로 팝업을 닫아 측정이 종료되지 않게 한다. |
| `측정 종료` | GPS 측정과 Live Activity를 종료한다. 외부 길안내 체류 시간이 환경별 기준을 충족한 경우에만 후기 팝업 후보로 전환한다. |

### 코스 후기 팝업

| 환경·상태 | `안 했어요` | `다녀왔어요` | X |
| --- | --- | --- | --- |
| Dev, GPS 미인증 | 미방문 사유 작성으로 이동한다. 사용자 연습기록 목록에는 표시하지 않는다. | 연습기록·방문 POST를 완료한 뒤 후기 작성으로 이동한다. | 연습기록·방문 POST를 완료한 뒤 팝업만 닫는다. 이후 연습기록에서 `후기 작성`을 선택할 수 있다. |
| Dev/Prod, GPS 인증 완료 | 미방문 사유 작성으로 이동한다. | 기존 인증 연습기록을 유지하고 후기 작성으로 이동한다. 방문 POST를 중복 호출하지 않는다. | 기존 인증 연습기록을 유지하고 팝업만 닫는다. 이후 연습기록에서 `후기 작성`을 선택할 수 있다. |
| Prod, GPS 미인증 또는 경로만 보기 | 미방문 사유 작성으로 이동한다. | 후기 작성으로 이동한다. Dev 테스트 우회용 연습기록·방문 POST는 호출하지 않는다. | 팝업과 후보만 닫는다. 연습기록을 새로 만들지 않는다. |

후기 작성 중 이탈하면 이미 생성된 연습기록은 유지되고 `후기 작성` 상태로 보인다. 최종 등록이 성공하면
해당 연습기록은 `작성 완료` 상태가 된다.

### 주차장 후기 팝업

주차장은 후기 작성 기능이 없으므로 어떤 상태에서도 `후기 작성` 또는 `작성 완료`를 표시하지 않는다.

| 상태 | `안 했어요` | `다녀왔어요` | X |
| --- | --- | --- | --- |
| GPS 미인증 또는 경로만 보기 | 미방문 사유 작성으로 이동한다. | 연습기록·방문 POST를 완료하고 `연습 기록에 추가되었습니다.` 스낵바를 표시한다. | 팝업과 후보만 닫으며 연습기록을 새로 만들지 않는다. |
| GPS 인증 완료 | 미방문 사유 작성으로 이동한다. | 기존 인증 연습기록을 유지하고 중복 POST 없이 스낵바만 표시한다. | 기존 인증 연습기록을 유지하고 팝업만 닫는다. |

주차장 `다녀왔어요` 등록 요청 중에는 `다녀왔어요`, `안 했어요`, X를 모두 비활성화한다.
성공하면 팝업을 닫고, 실패하면 팝업을 유지해 다시 시도할 수 있다.

## 변경 시 확인할 사항

- 대기 시간은 `RootReducer.reviewPromptDelay` 한 곳에서만 조정한다.
- Dev 전용 우회는 반드시 `#if DEBUG`로 제한하고 Prod 정책을 바꾸지 않는다.
- UserDefaults에는 장소 ID·이름·모드·상태·시각 등 최소 상태만 저장하고 원본 GPS 좌표는 저장하지 않는다.
- Live Activity UI 변경은 `AGENTS.md`의 사전 사용자 승인 규칙을 따른다.
