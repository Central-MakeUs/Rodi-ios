# RODI 버전 이력과 패치노트

이 문서는 App Store의 버전별 `새로운 기능` 문구와 내부 배포 범위를 함께 기록한다. 사용자에게 노출하는 패치노트에는 검증되지 않은 안전·사고 예방·주차 가능 여부 보장 표현을 사용하지 않는다.

## 1.4.0

### App Store 패치노트

- 직접 찾은 장소를 나만의 운전 연습 코스로 등록할 수 있어요.
- 출발지, 경유지, 도착지를 지도와 장소 검색으로 선택해 코스를 만들 수 있어요.
- 마이페이지에서 등록한 코스와 활동을 더 편하게 확인하고 관리할 수 있어요.
- 지역 검색, 현재 위치, 코스·주차장 상세 화면과 모바일 권한 흐름을 개선했어요.
- 앱 이용 흐름과 지도 탐색 경험을 안정화했어요.

### 내부 변경 요약

- 장소 검색·핀 수정·경유지 편집을 포함한 사용자 코스 등록 flow를 추가했다.
- 연습기록·내 게시글·차단목록을 마이페이지에서 확인·관리하는 흐름을 보완했다.
- 지역 검색 결과와 지도 viewport 동기화, 코스·주차장 바텀시트의 Safe Area·길안내 UI를 정비했다.
- 위치 권한 변경 뒤 앱 복귀 시 시스템 권한을 다시 확인하도록 보완했다.

## 1.3.0

### App Store 패치노트

- 연습하러 가기 후 실시간 현황으로 코스와 주차 연습 상태를 확인할 수 있어요.
- 연습을 마친 뒤 기록을 남기고, 코스 후기 작성·수정·삭제를 할 수 있어요.
- 마이페이지에서 연습기록과 내가 작성한 후기를 더 편하게 확인할 수 있어요.
- 코스·주차장 상세와 지도 목록 탐색 경험을 개선했어요.
- 로그인과 온보딩 진입 흐름을 안정화했어요.

### 내부 변경 요약

- 사용자가 시작한 연습 세션에서만 GPS 기반 측정과 Live Activity를 시작한다.
- 코스는 경로선 150m 이내의 인정 이동거리와 `min(전체 거리 × 40%, 5km)` 기준으로, 주차장은 장소 반경 150m 진입 기준으로 완료 상태를 처리한다.
- 후기 작성·수정·삭제, 신고·차단, 내 게시글·연습기록 갱신 흐름을 추가·보완했다.
- 외부 길안내 복귀 후 후기 팝업, 실시간 현황 권한 안내, 코스·주차장 바텀시트 흐름을 정비했다.
- access token 갱신과 서버의 온보딩 완료 상태를 기준으로 로그인 진입을 안정화했다.
- 앱 내 LicenseList 기반 오픈소스 라이선스 목록을 제공한다.

## 1.2.0

### App Store 패치노트

- 지역명과 코스·주차장 이름으로 원하는 연습 장소를 검색할 수 있어요.
- 원하는 연습 유형과 조건에 맞춰 장소를 필터링할 수 있어요.
- 적용한 필터와 관련된 장소를 목록 상단에서 먼저 확인할 수 있어요.
- 나에게 맞는 운전 연습 장소를 더 빠르게 탐색할 수 있도록 검색 경험을 개선했어요.

### 내부 변경 요약

- 지도 기반 장소 검색, 최근 검색어, 필터 적용과 목록 우선순위 표시를 추가했다.

## 1.1.0

### App Store 패치노트

- 카카오와 Apple 계정으로 간편하게 시작할 수 있어요.
- 운전 경험을 바탕으로 나만의 운전 레벨과 추천 연습 유형을 안내해드려요.
- 홈 화면 바텀시트의 목록 탐색과 지도 이용 경험을 개선했어요.
- 내 정보, 운전 목표, 저장한 장소를 확인할 수 있는 마이페이지를 추가했어요.
- 로그아웃과 회원탈퇴 기능을 추가했어요.

### 내부 변경 요약

- 소셜 로그인과 온보딩, 사용자 레벨·운전 목표, 저장 장소 및 계정 관리 기능을 도입했다.

## 1.0.1

### App Store 패치노트

- 일부 기기에서 앱 미리보기 스크린샷이 보이지 않는 문제를 해결했어요.
- 검색 키워드를 최적화했어요.
- 기존 코스 경로 안내에 현재 위치까지의 경로를 추가했어요.
- 설치된 앱 버전과 최신 앱 버전이 다르면 업데이트 안내 문구를 표시해요.

### 내부 변경 요약

- 앱 미리보기, 검색 키워드, 외부 길안내 시작 경로, 강제·권장 업데이트 안내를 보완했다.

## 운영 규칙

- 새 버전 배포 전, 사용자용 패치노트와 내부 변경 요약을 함께 추가한다.
- 사용자용 패치노트는 3~5개 항목으로 간결하게 작성하고, 권한·외부 앱·측정 기능은 실제 동작 범위를 벗어나지 않게 표현한다.
- App Store Connect의 `새로운 기능`, 심사 메모, 스크린샷, 개인정보·위치 관련 고지는 같은 Release 기능과 일치해야 한다.
