# QA 이슈 로그

## 목적

이 문서는 Notion에서 전달받은 QA 이슈의 처리 상태만 간결하게 기록한다. 사용자는 이슈를 대화로 전달하고, 분류·TODO 등록·완료 이동은 작업자가 담당한다. 장기 구조 개선·리팩터링 backlog는 [미해결 항목](UNRESOLVED_ITEMS.md)에서 관리한다.

## 기본 QA 환경

- 기기: iPhone 12 Pro
- OS: iOS 18.7.8

항목에 환경을 반복해서 쓰지 않는다. 로그인 상태·권한·네트워크처럼 결과에 직접 영향을 준 조건만 필요할 때 짧게 덧붙인다.

## 기록 규칙

- MUST 새 이슈를 `## TODO`에 한 줄 체크박스로 기록한다.
- MUST 해결한 항목을 `## 처리 완료`로 옮기고, 짧은 처리 결과를 남긴다.
- MUST 로그·스크린샷에 token, credential, 정확한 사용자 좌표, 개인 식별 정보를 남기지 않는다.
- SHOULD 화면 경로와 사용자에게 보이는 결과를 먼저 적고, 원인 설명은 필요한 경우에만 덧붙인다.
