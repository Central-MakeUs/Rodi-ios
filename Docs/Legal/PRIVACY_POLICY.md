## 1. 처리하는 개인정보 항목

운영팀은 서비스 제공을 위해 다음 정보를 처리합니다.

| 구분 | 처리 항목 | 처리 목적 |
| --- | --- | --- |
| 소셜 로그인 및 회원 식별 | 소셜 로그인 제공자, 제공자별 회원 식별 정보, 닉네임, 서비스 내부 회원 식별 정보 | 로그인, 회원 식별, 계정 복구, 서비스 제공 |
| 인증 및 세션 | 접근 토큰, 갱신 토큰 등 인증 세션 정보 | 로그인 상태 유지, 인증 및 보안 |
| 온보딩 및 운전 프로필 | 운전 기간, 최근 운전 빈도, 도로 주행 경험, 혼자 운전 범위, 혼자 주차 수준, 선호 연습 유형, 차종, 운전 목표, 산출된 운전 레벨 | 맞춤형 연습 유형 및 코스 추천, 회원 프로필 구성 |
| 서비스 이용 정보 | 북마크한 장소, 저장 목록, 운전 목표 수정 정보 | 저장 기능 및 마이페이지 제공 |
| 위치정보 | 현재 위도·경도, 지도 뷰포트와 장소 조회에 필요한 좌표 | 주변 장소 조회, 거리 정렬, 지도 표시, 경로 참고 및 외부 길안내 연동 |

운영팀은 소셜 로그인 과정에서 발급되는 인증 코드를 로그인 처리 목적으로 일시적으로 이용할 수 있으나, 해당 인증 코드를 장기 보관하지 않습니다.

## 2. 기기 내 저장 정보

Rodi는 서비스 편의와 보안을 위해 다음 정보를 이용자의 기기에 저장할 수 있습니다.

| 저장 위치 | 저장 정보 | 목적 |
| --- | --- | --- |
| UserDefaults | 미완료 온보딩 초안 및 선택 항목, 최근 로그인한 소셜 로그인 제공자, 온보딩 표시 상태 | 앱 종료 후 온보딩 진행 상태 복원, 로그인 화면 편의 제공 및 화면 진행 상태 관리 |
| Keychain | 접근 토큰, 갱신 토큰 | 로그인 세션의 안전한 유지 |

UserDefaults에 저장한 정보는 앱 삭제 또는 관련 기능 초기화 시 삭제됩니다. Keychain에 저장한 인증 토큰은 로그아웃, 탈퇴, 만료 또는 인증 무효화 시 앱이 삭제하며, iOS의 Keychain 특성상 앱 삭제만으로 즉시 삭제되지 않을 수 있습니다.

## 3. 개인정보 처리 목적

운영팀은 개인정보를 다음 목적에서만 처리합니다.

1. 소셜 로그인, 회원 식별, 로그인 상태 유지 및 계정 복구
2. 온보딩 진행 상태 복원 및 운전 프로필·레벨·추천 정보 제공
3. 코스·주차장 탐색, 저장 목록 및 마이페이지 기능 제공
4. 현재 위치를 활용한 주변 장소 조회, 거리 정렬, 지도 표시 및 길안내 연결
5. 고객 문의 처리 및 서비스 운영·보안 관리

## 4. 위치정보의 처리

1. 이용자가 위치 권한을 허용한 경우에만 현재 위치 좌표를 이용합니다.
2. 현재 위치 좌표는 장소 목록을 조회하기 위해 Rodi 서버에 요청 값으로 전달될 수 있습니다.
3. 운영팀은 현재 위치 좌표를 이용자의 이동 이력으로 별도 저장하지 않습니다.
4. 지도·경로·길안내 기능 이용 시 필요한 출발지, 도착지 또는 경유지 좌표가 카카오 관련 서비스로 전달될 수 있습니다.
5. 위치정보 처리에 관한 자세한 내용은 위치기반서비스 이용약관을 따릅니다.

## 6. 보유 및 이용 기간

1. 회원 및 운전 프로필 정보는 회원 탈퇴 또는 처리 목적 달성 시까지 보유합니다.
2. 탈퇴 요청 회원의 계정 복구 가능 기간은 탈퇴 요청일부터 3일입니다. 해당 기간 중 동일 소셜 계정으로 계정 복구가 가능합니다.
3. 위치 좌표는 현재 요청 처리와 기능 제공을 위해 이용하며, 위치 이력으로 별도 저장하지 않습니다.
4. 인증 토큰은 로그아웃, 탈퇴, 만료 또는 인증 무효화 시 삭제합니다. iOS Keychain의 시스템 보관 특성은 별도로 적용될 수 있습니다.
5. 법령에 따른 보관 의무가 있는 경우에는 해당 기간 동안 보관합니다.
